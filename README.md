# Luminous Spa

App móvil para la reservación de citas en un spa, hecha con React Native (Expo) y Firebase.

## Características

- Registro e inicio de sesión (correo y Google)
- Catálogo de servicios y terapeutas
- Agendar, consultar y ver el detalle de citas
- Calendario e historial de citas
- Perfil de usuario editable
- Notificaciones y sección de soporte

## Tecnologías

- React Native 0.76 y Expo 52
- Firebase (Authentication y Firestore)
- React Navigation
- React Native Paper y React Native Elements
- react-native-calendars y expo-notifications

## Cómo ejecutarlo

1. Instala las dependencias: `npm install`
2. Configura tu proyecto de Firebase en `database/firebase.js`
3. Inicia la app: `npm start` (o `npm run android`)
